# Architecture Notes

This project included AWS architecture planning for a SaaS-style cloud solution.

## Architecture Topics Covered

The architecture section included concepts such as:

- AWS Well-Architected Framework
- ECS with Fargate
- Amazon Aurora
- CloudFront
- Route 53
- IAM
- AWS WAF
- API Gateway
- multi-region design
- data residency
- compliance
- availability
- disaster recovery
- design justification

## Architecture Reflection

The architecture part of the project helped me think about how different AWS services work together in a complete cloud solution. It also showed me that good architecture is not only technical. It must also consider security, compliance, cost, reliability, and user access.
