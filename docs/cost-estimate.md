# Cost Estimate Notes

This document summarizes the cost-awareness part of the Cloud Based Technologies project.

## Cost Areas Considered

The project required cost estimation and design thinking around AWS services such as:

- EC2
- EBS
- S3
- CloudFront
- Systems Manager
- AWS support options
- Trusted Advisor or Business Support
- Glacier storage
- high availability and fault tolerance

## Cost-Awareness Reflection

The cost-estimation section helped me understand that cloud design is not only about choosing services. It is also about understanding how those services affect monthly spend, scalability, availability, and long-term maintenance.

A strong AWS design should balance performance, reliability, security, and cost. This project helped me practise that balance by requiring pricing decisions alongside technical architecture decisions.
