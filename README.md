# AWS-Cloud-Architecture-Project
Portfolio documentation for an assessed AWS cloud architecture, cost estimation, and networking project.

This repository documents my assessed Cloud Based Technologies formative project. The project received a recorded grade of 86% and forms part of my learning portfolio in cloud architecture, AWS cost awareness, practical networking, and technical documentation.

## Project Overview

This was an individual NQF Level 5 formative project worth 110 marks and contributing 40% toward the final module mark. The project assessed a broad range of AWS cloud skills, including architecture design, cost estimation, high availability, security, and hands-on networking configuration.

The project was divided into three major sections:

- Question 1: AWS SaaS architecture and Well-Architected Framework analysis
- Question 2: AWS cost estimation and high-availability planning
- Question 3: Practical AWS networking implementation using VPCs, subnets, EC2, security groups, routing, and SSH access

## Skills Demonstrated

- AWS architecture planning
- Well-Architected Framework thinking
- SaaS application design
- ECS with Fargate, Aurora, CloudFront, Route 53, IAM, WAF, and API Gateway concepts
- Multi-region availability and failover planning
- Data residency and compliance awareness
- AWS cost estimation using EC2, EBS, S3, CloudFront, support, and Glacier considerations
- VPC design with public and private subnets
- Security group and route table configuration
- Technical explanation and reflective documentation

## Result

The project received a recorded grade of 86%.

## Reflection

This project helped me connect cloud theory with practical infrastructure design. It required me to critically think about architecture, cost, security, availability, and implementation together rather than treating them as separate topics.

The result shows that I can complete a broad technical project to a good assessed standard.
